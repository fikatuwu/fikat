Thêm VPS

⚠️ Mật khẩu được mã hoá AES-256 trước khi lưu. VPS cần cài đặt ffmpeg, rclone (có nút Cài đặt tự động).

Tạo luồng phát

1. Thông tin cơ bản
2. Cấu hình Stream

YouTube Studio → Phát trực tiếp → copy "Khoá luồng" dán vào đây. Lưu mã hoá AES.

3. VPS & Nguồn Video
Chọn file video

Click ★ trên từng file để đánh dấu ưu tiên. Playlist = [file ★ theo mode 1] + [file còn lại theo mode 2].

Chọn thư mục video ở trên để load file

5. Lên lịch phát

Backend tự động poll mỗi 30s để start/stop luồng đúng giờ.
